The design

Read-only checks gather device evidence. Guided procedures support investigation, while owner-scoped incident storage and revision checks reject stale updates.

All 96 automated tests passed on the published source checkout. The controlled repair lab separates suggested actions from approved execution and checks the resulting state.

02 / NATIVE SOFTWARE & VERIFICATION

ReverseLab

Check a decoder rewrite.

A guided debugging example with a side-by-side comparison. Pick a packet, compare what C and Python read, and see how reversing two bytes changes the message number. Then compare the corrected version.

Same packet. Original: 4,660. Buggy rewrite: 13,330.

C · Python · Clang · REA / Ghidra · JavaScript

Compare the decoders ↗View source ↗
How the comparison works +

The use case

Check a replacement decoder against an executable reference. An asymmetric sequence exposes a byte-order mistake that symmetric sequences would hide.

The verification

Frozen candidates passed 7,000 comparisons on 1,000 previously unused inputs per fixture, repeated across builds. The deliberate endian mutant failed 333 new inputs per packet build. Real Ghidra evidence is attached to the stripped packet artifact.

The boundary

Three self-authored fixtures with source known during reconstruction, built with Codex assistance. The browser displays recorded results; native replay runs locally. Actual firmware integration needs a new adapter. Sampled agreement is not an equivalence proof.
