SignalForge

Work with the recording.
Keep the useful part.

Open a microcontroller log, navigate its signal timeline, and isolate a time range to export. Event markers expose missing readings, late arrivals and duplicates without losing the original arrival order.

v0.1 · Browser recording workspace. CSV inspection works in the browser; examples are simulated, and the Python capture utility is tested through virtual serial I/O.

JavaScript · Python · CSV · Serial capture

Open recording workspace ↗View source & capture utility ↗
What it establishes +

The use case

Review a microcontroller logger's CSV when readings stop or arrive out of order. Each event keeps the surrounding evidence and can be replayed.

The engineering

Wrap-aware sequence tracking, explicit boot segments, late recovery, duplicate detection, replay-prefix counters and portable sessions. One detector serves the browser and Node tests.

The boundary

Single-channel recordings with arrival timestamps and a uint32 counter. Simulated examples and virtual serial tests are separate from physical-device validation. Gaps do not independently establish a hardware or network fault.

02 / NATIVE SOFTWARE & VERIFICATION

ReverseLab

Check a decoder rewrite.

Compare your C function with a Python rewrite on the same input bytes. Run your files locally, inspect exact disagreements, and save a report you can reopen in the browser. A guided packet example shows the workflow.

Same packet. Original: 4,660. Buggy rewrite: 13,330.

C · Python · Clang · REA / Ghidra · JavaScript

Try the guided example ↗Compare your programs ↗View source ↗
How the comparison works +

The use case

Check a replacement decoder against an executable reference. An asymmetric sequence exposes a byte-order mistake that symmetric sequences would hide.

The verification

Frozen candidates passed 7,000 comparisons on 1,000 previously unused inputs per fixture, repeated across builds. The deliberate endian mutant failed 333 new inputs per packet build. Real Ghidra evidence is attached to the stripped packet artifact.

The boundary

Three self-authored fixtures with source known during reconstruction, built with Codex assistance. The guided example displays recorded results. Your own C/Python files run through an opt-in local runner: 0–64 input bytes, uint32 output, on macOS/Linux. The hosted page opens saved reports. Programs must be trusted; this is not a security sandbox. Firmware interfaces need an adapter. Sampled agreement is not an equivalence proof.
